## 개인정보 삭제 예시

운영 정책과 법적 보존 의무를 확인한 뒤 실행한다.

```sql
DELETE FROM inquiries
WHERE created_at < datetime('now', '-1 year');
```

실행 전 D1 내보내기/감사 절차를 따르되 백업에도 동일한 보존기간을 적용한다.

## 장애 시 표현 원칙

- DB가 끊겼을 때 접수 성공을 표시하지 않는다.
- 지도·PDF·이미지가 없으면 대체 설명과 오류 상태를 보인다.
- AI 기능을 추가할 때 인증되지 않으면 `연결 필요`로 차단한다.
