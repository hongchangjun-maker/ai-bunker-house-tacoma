# 확장 로드맵

## Gate 0 — 사실 확인

- 소유·권리·경계·건축물대장·영업 상태
- 드론·LiDAR 현황측량과 시설 안전진단
- 지질·암반·지하수·사면·배수·생태 기준선

## Gate 1 — 타당성

- 법규·용도·환경·재해 영향 검토
- 144명 프로그램 면적, 피난, 공조, 위생 설계
- 식량·물·에너지 질량수지와 CAPEX/OPEX 범위
- 중단 조건과 단계별 투자 의사결정표

## Gate 2 — 디지털 확장

- 실제 측량 좌표 기반 3D 지형·BIM 뷰어
- 설비 부하·재고·인력 시나리오 시뮬레이터
- 국/영문 전체 콘텐츠 CMS와 승인 이력
- 관리자 문의 처리, 보존기간 자동화, 감사 로그
- 접근 권한이 있는 투자자 자료실

## Gate 3 — 현장 실증

- 지상부 재생 파일럿
- 독립 설비 모듈과 스마트팜 실증
- 재난 시나리오 기반 운영 훈련과 사람 중심 검증
- 검증 결과에 따른 규모 축소·확대 또는 NO-GO 결정

프랜차이즈 또는 2·3호 확장은 동일 도면 복제가 아니라 입지 검증 기준, 모듈 인터페이스, 운영 프로토콜의 표준화를 목표로 한다.
