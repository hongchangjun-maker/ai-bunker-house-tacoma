# 디자인 시스템

## 방향

`재난 대응형 럭셔리 레지던스 + 검증 가능한 전략 인프라`를 목표로 했다. 군사 게임, 공포, 무기 이미지는 사용하지 않는다.

## 컬러

- Deep Navy `#07111D`: 운영·기술·야간 배경
- Ink `#0C1721`: 밝은 면의 제목·본문
- Paper `#EFF2EF`: 건축 제안서 같은 밝은 섹션
- Emerald `#55D7B2`: 연결·건강·검증된 상태
- Gold `#E8BB68`: 주의·미확정·중요 게이트

## 타이포그래피

- 영문/UI: Manrope
- 국문: Noto Sans KR
- 제목은 얇은 무게와 큰 자간 대비, 데이터와 상태는 작은 대문자 레이블로 구분한다.

## 컴포넌트

- `eyebrow`: 섹션 상태·영문 분류
- `concept-notice`: 비공식·미검증 상태를 첫 화면 직후 고정 전달
- `floor-stack`: 키보드, 마우스, 터치를 모두 지원하는 층별 탭
- `gallery-card`: 원본 복제 없이 생성한 콘셉트 이미지와 생성 상태 표시
- `risk-strip`: GO/NO-GO 선행조사
- `system-grid`: 시스템별 목표와 조건의 동일한 위계

## 반응형

- 1100px: 복합 그리드 축소
- 820px: 모바일 내비게이션, 1열 위치 분석, 가로 스크롤 단면도
- 560px: 카드 스택, 1열 폼, 1열 시스템

## 접근성

- 본문 건너뛰기 링크
- 모든 생성 이미지의 설명형 대체 텍스트
- 확대 보기 `Escape` 닫기
- 층별 탐색의 tab/tabpanel 의미와 키보드 포커스
- `prefers-reduced-motion` 대응
- 폼 레이블, 오류/성공 `role=status`
