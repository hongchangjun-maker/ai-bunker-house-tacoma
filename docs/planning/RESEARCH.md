# 공개 리서치 기록

조사일: 2026-08-12

## 확인된 사실

1. 장수군 공식 관광 숙박 목록에 `(유)타코마장수관광농원`, 주소 `전북특별자치도 장수군 계남면 장수로 2662-11`, 전화번호 `063-353-8200`이 수록되어 있다.
2. 해당 장수군 페이지는 공공누리 제4유형(출처표시 + 상업적 이용 금지 + 변경 금지)으로 표시된다. 따라서 페이지 사진·문구를 상업 콘셉트 사이트에 복제하지 않았다.
3. 대한민국 구석구석의 과거 소개에는 객실, 사우나, 수영장, 찜질방, 컨벤션센터 등이 있는 시설로 설명된다. 현지 사정 변동 가능성을 안내하므로 현재 운영 증거로 사용하지 않는다.
4. 장수군청은 계남면 자동차 접근에 장수 IC를 포함한 권역별 경로를 안내한다.
5. 한국민족문화대백과는 장수분지를 해발 약 400~500m, 산악지형으로 설명한다. 대상지 개별 고도는 측량값이 아니다.

## 상충하거나 확인이 필요한 정보

- 2025년 보도성 콘텐츠에는 시설이 장기간 미운영·방치되었다는 내용이 있다. 공식 숙박 목록 등재와 실제 영업은 동일하지 않으므로 사이트에는 `현재 운영 여부 확인 필요`라고 표시했다.
- 소유권, 담보·권리, 건축물대장, 용도, 영업신고 상태, 구조안전, 부지 경계는 공개 웹 검색만으로 확정하지 않았다.
- OpenStreetMap 핀은 주소 도로 검색 결과를 바탕으로 한 근사 위치이며 정밀측량 좌표가 아니다.
